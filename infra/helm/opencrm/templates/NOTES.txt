Voraussetzung — DB-Secret (extern verwaltet, z. B. External Secrets Operator):
Das Secret "{{ .Values.backend.env.dbSecretName }}" muss im Namespace
"{{ .Release.Namespace }}" existieren und folgende Keys enthalten:

  DB_URL                 z. B. jdbc:postgresql://<host>:5432/opencrm?sslmode=verify-full
  DB_USER                App-Rolle (opencrm_app, ohne BYPASSRLS)
  DB_PASSWORD
  DB_MIGRATOR_USER       Migrations-Rolle (opencrm_migrator, Schema-Owner)
  DB_MIGRATOR_PASSWORD

Nur fuer erste Tests (Produktion: External Secrets Operator, nie Klartext im Repo):

  kubectl -n {{ .Release.Namespace }} create secret generic {{ .Values.backend.env.dbSecretName }} \
    --from-literal=DB_URL='jdbc:postgresql://<host>:5432/opencrm' \
    --from-literal=DB_USER='opencrm_app' \
    --from-literal=DB_PASSWORD='<...>' \
    --from-literal=DB_MIGRATOR_USER='opencrm_migrator' \
    --from-literal=DB_MIGRATOR_PASSWORD='<...>'
